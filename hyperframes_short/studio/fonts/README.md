# Font cục bộ cho HFS studio

woff2 tải từ Google Fonts (subset vietnamese + latin + latin-ext) bằng `python studio.py fonts`; danh mục + @font-face ở `faces.json`.
Tất cả là font mã nguồn mở theo SIL Open Font License 1.1 (Be Vietnam Pro, Playfair Display, JetBrains Mono, Chivo Mono, Newsreader,
Old Standard TT, Spectral, Xanh Mono) -- được phép đóng gói kèm dự án; không bán riêng file font.
