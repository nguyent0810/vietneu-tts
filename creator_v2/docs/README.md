# creator_v2/docs: tư liệu lịch sử từ V2

Thư mục này chép nguyên `docs/` của repo `Youtube_Creator_V2` khi gộp vào vietneu-tts (#100, 03–04/11/2026). Đường dẫn máy và email đã được thay bằng chỗ trống.

**Đây là tư liệu lịch sử, không phải hướng dẫn hiện hành.** Nhiều file còn nhắc kênh FS/BUD, tracker cũ (`tk`, issue của V2) hoặc đường dẫn Windows của máy cũ. Luật đang áp dụng nằm ở `creator_v2/CLAUDE.md` và `creator_v2/AGENTS.md`. Hai file mà agent sản xuất vẫn đọc trực tiếp là `docs/codex/long-rules.md` và `docs/codex/long-cheatsheet.md`.

Code đọc các file sau khi chạy: lexicon và hồ sơ ảnh AI trong `docs/pm/ai-image/`, mẫu brief trong `docs/pm/tickets/`.
